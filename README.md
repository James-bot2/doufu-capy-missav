# doufu-capy-missav

CapyPlayer MissAV 源组件（接 missav.ai）。

## 安装

CapyPlayer「组件」页点 `+`，粘贴下面的链接，预览后安装：

```
https://raw.githubusercontent.com/James-bot2/doufu-capy-missav/main/MissAV_CapyPlayer_source_v1.0.0.js
```

不用填 Cookie，不用部署 Worker。

## 模块

- 最新更新 / 今日热门 / 分类浏览 / 搜索 / TOP 榜单
- 详情出 surrit 播放地址，多清晰度时可切换线路

## 说明

- 主站 missav.ai；missav.live / .fans / .media / .ai / .ws 是同一站的不同后缀，组件会在后缀之间自动切换。
- v1.0.0：按 [CapyPlayer 组件开发指南](https://capyplayer.feifeiduck.com/en/dev/widget/widgetdev)编写。
