# doufu-capy-missav

CapyPlayer MissAV 源组件（接 missav.ai）。

## 安装

CapyPlayer「组件」页点 `+`，粘贴下面的链接，预览后安装：

```
https://raw.githubusercontent.com/James-bot2/doufu-capy-missav/main/MissAV_CapyPlayer_source_v1.1.0.js
```

不用填 Cookie，不用部署 Worker。

## 模块

- 最新更新 / 今日热门 / 搜索 / TOP 榜单 / 我的收藏（填同步地址后显示）
- 分类：0922 的 13 个分类组全量（134 项）+ 女优 49 项 + 发行商 36 项
- 详情出 surrit 播放地址（带 Referer），多清晰度时可切换线路

## 说明

- 主站 missav.ai；missav.live / .fans / .media / .ai / .ws 是同一站的不同后缀，组件会在后缀之间自动切换。
- v1.1.0：修播放（补 Referer + 多档直链）、分类全量、新增同步收藏。按 [CapyPlayer 组件开发指南](https://capyplayer.feifeiduck.com/en/dev/widget/widgetdev)编写。
